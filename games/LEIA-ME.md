# Pasta de jogos 🎮

Esta é a pasta de jogos padrão do HUB (aba **Jogos**).

- Coloque aqui os **executáveis** (`.exe` ou atalhos `.lnk`) ou **pastas de jogos**.
- Ou, no app, clique em **📁 Trocar** e aponte direto para a sua pasta de jogos de sempre
  (ex.: onde ficam os jogos que você baixa).
- Clique num card para abrir o jogo. Clique direito para escolher o executável, renomear, etc.

> Os jogos em si **não** vão para o GitHub (estão no `.gitignore`). Só este aviso é versionado.
