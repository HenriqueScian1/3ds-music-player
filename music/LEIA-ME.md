# Coloque suas músicas aqui 🎵

Esta é a pasta de músicas padrão do **3DS Music Player**.

- Copie seus arquivos de áudio (`.mp3`, `.flac`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav`, `.wma`)
  para dentro desta pasta — pode usar subpastas à vontade.
- Abra o app (ou clique em **🔄 Recarregar**) e as músicas aparecem na Biblioteca,
  já com capa, título, artista e gênero lidos das tags.
- As músicas baixadas pela aba **Baixar** também são salvas aqui.

> Os arquivos de áudio desta pasta **não** vão para o GitHub (estão no `.gitignore`).
> Só este aviso é versionado, para a pasta existir depois de clonar o repositório.
